How to run the game:
  • Click blocks to mine them.
  • Use the inventory buttons to select a block or tool..
  • Right-click on empty space to place the selected block.
  • Click the restart button to reset the world.
      • Controls:
  • Left click: break a block
  • Right click: place the selected block
  • Inventory buttons: choose a block or tool
  • Restart: reset the world
